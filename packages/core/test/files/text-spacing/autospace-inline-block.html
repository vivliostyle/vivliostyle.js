An atomic inline is not a character, so the text inside and outside it does not adjoin, and text-autospace inserts no spacing at its boundaries (CSS Text 4 § 8.4.1). The spacing inside it is kept. The “normal” lines (native in browsers that support it) must be the same as the “ideograph-alpha” lines (polyfill), except for the dates.

text-autospace: normal
