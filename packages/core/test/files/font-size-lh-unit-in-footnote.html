The footnote at the page bottom must have the same letter-spacing as the inline "Wide" above: 1lh is the 40px line height of the paragraph, not the line height of the root. For the paragraph with the percentage computed line height it is the 24px of `calc(150%)`, for the paragraph whose ancestor declares `line-height: 1lh` it is the 30px of that ancestor, and for the paragraph with `line-height: min(40px, 2em)` it is the 32px that the math function computes. The paragraphs with `line-height: max(1lh, 5px)`, `line-height: round(1lh, 7px)` and with `line-height: 2lh` on the footnote itself (the grey "Wide" boxes) have a line height of 40px, 42px and 80px, the line height of their source parent and the results of the functions there, and the paragraph with `line-height: round(40px, 7px)` is 42px, so the footnote with `font-size: 1lh` is 42px as well. The paragraph whose own font size is `math` (which only the browser resolves) has an absolute line height of 40px, so the footnote with `font-size: 1lh` is 40px as well.
