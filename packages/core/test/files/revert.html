The revert keyword

Every list item below must be green.

  1. A1 revert with nothing below it inherits
  2. A2 revert ignores layers and rolls back the origin
  3. A3 revert rolls back the layers of its origin
  4. A3x revert rolls back a lower-specificity rule
  5. A4 revert with !important
  6. A5 revert loses to a stronger declaration
  7. C1 all: revert
  8. C2 revert on a custom property
  9. C3 revert written in a var() fallback
  10. B2 revert to the UA font-weight: this must be bold

The list below must show its markers.

  1. B1 revert to the UA display: list-item
  2. B1 second item

D1 revert rolls back the whole author origin, layers included, so the break-before: page declared in a layer is gone and this paragraph must stay on the same page as the list above.
