The root element sizes itself with font-size: 2rlh and line-height: 2lh. Per CSS Values, lh and rlh used on the root element's own font and line-height properties resolve against the initial font and line-height values, so neither depends on the other and both give twice the initial line height.

The teal (1rem), purple (1rlh) and green (40px) boxes above must all be the same height.
